# 设计与修订判断

这些是从多轮成品反馈中提炼的工作默认值，不是每张照片都必须使用的模板。先读取用户本轮要求。

## 摄影与构图

原片是主角。云少的天空通常适合浅色线网；白云上的白线几乎不可见，反而容易变成脏白纹理。蓝灰色云也不能自动当成蓝天。晚霞、明暗变化与摄影主体共同构成视觉重心，不能只按蓝色像素数量定位置。

把负空间看成带有孔洞的形状：较宽的清晰区容纳路网核心，狭窄分支容纳渐隐的道路末端，文字需要独立且连续的可读区域。地图可以延展到画面上沿或横向天空，尤其当用户希望天空被充分利用时。不要为“统一边距”留下刻意的圆弧空白。

同一张照片可以选择近景城区、城市海湾或更宽的区域地图。先挑能表现所在地的地理尺度，再尝试移动、等比例缩放；不非均匀拉伸地图来迁就天空。

## 信息层级

| 要素 | 默认处理 | 需要避免 |
|---|---|---|
| 主路与河岸/海岸 | 最清晰的骨架，核心区适当加实 | 所有线等粗、等淡 |
| 次路与街巷 | 丰富但低于主路，保持真实连接 | 为图案效果随机生成网格 |
| 建筑/街区 | 更细更轻，提供城市颗粒感 | 密度均匀、铺成白块 |
| 湖泊/河面 | 以轮廓为主，填色极淡且透明 | 大片不透明色块、错误填满岛屿 |
| 等高线 | 真实 DEM 推导，疏密受地形决定 | 装饰性波浪线冒充地形 |
| 城市名 | 较大的疏排衬线大写，仍然克制 | 缩成看不见的小注释或大海报标题 |
| 拍摄区域 | 鲜红点，地点名紧邻，必要时两行 | 暗红、半透明红、针尖小点或悬空标签 |
| 辅助地名 | 2–4 个有依据的地名即可 | 每条路都标字 |

起点可采用暖灰白/象牙色线条，主路强于支路，建筑弱于道路。点可从 `#F23A2C` 起调，通常不需要发光。大小应随成品尺寸缩放并在预览中可辨识，不能依赖显示器 DPI。

城市标题和地点名各司其职：如 `BEIJING` 放在原来适合主标题的位置，`BEIJING NO. 4 HIGH SCHOOL` 靠红点。避免将坐标作为装饰。指北针与比例尺是可选；比例尺只有按实际投影正确计算时才加入。

## 自然透明的做法

先在真正透明的画布绘制所有地图要素；透明像素不含可见底板。对实际线条 alpha 施加空间变化，而不是给一个矩形地图截图整体降透明度。

组合几类控制：保护主体的可用区域遮罩、蓝天/云层置信度、沿地图边缘的长过渡、不同要素的衰减速度，以及为文字局部减淡的底图。主路可延伸得较远，支路/建筑较早消失，保持“树根分支消失”的观感。

渐变不是无止境降低透明度。核心要有能读懂的路网；边缘渐隐不应把整个地图熔成几根线。不要从一个规则圆形或矩形边界开始均匀羽化后就交付。若仍能看出地图外接框：优先补齐数据覆盖、改变地理构图、改变各要素末端衰减及遮罩，再调整全局透明度。

纸张印刷感可由细小、不均匀但稳定的墨线透明度产生。不要叠加影响原片的全画面颗粒、褪色或色偏。

## 用户反馈对应的改法

| 反馈 | 优先修改 |
|---|---|
| 太小、太简陋 | 扩展有真实细节的地理范围/数据层，再增加合理尺寸；保住核心对比 |
| 云上重叠太多 | 移动实际密集线网、点与文字到蓝天；云附近局部减弱，别全图减淡 |
| 边缘太方、圆弧刻意 | 查数据截断与统一羽化；按摄影遮罩和要素级衰减，局部延伸支路 |
| 内部虚实不够 | 主路、水岸加实，次路次之，建筑弱；不是所有线一起变粗 |
| 标题/校名太小 | 调整文字层级与留白，校名保持在红点旁，检查手机预览可读性 |
| 画质下降或被删减 | 立刻检查原文件、EXIF方向、DPI绘制、导出分辨率；以原生原片重新合成 |

一次改版应能说清解决了什么。对于分数差别很小的自动选位结果，描述为小幅优化或验证先前判断；不要承诺“已经和网图完全一样”。

## 构图平衡优先于最大蓝天矩形

先用整体缩略图识别视觉重量：主体的面积、明暗对比、纹理密度和色彩强调，以及视线通向的区域。地图作为第二视觉中心，应与主体呼应，同时保留连接两者的呼吸空间。不能机械地放到主体对角，也不能把摄影重要的空旷感全部填掉。

当两块天空都安全时，比较位置有明显差别的预览，依次判断：
1. 主体仍是第一视觉中心吗？地图是否平衡过重的一侧？
2. 路网/地形的实际密集部分落在哪里？不要只看外接框；海面空白不等于有地图重量。
3. 地名、红点、标题是否各有可读空间？地图是否与云带、主体轮廓贴得过紧？
4. 是否保留连续留白，边缘是否沿真实地理分支自然消散？

仰口实例：左侧寿字岩厚重，上方右侧蓝天宽阔。中上方案虽有较高启发式分数，却把地形细节放在岩壁上方；右上方案让地图与岩壁形成呼应，保留中间天空。因此选择右上，面积约19%，而非继续追求最大约23%。这些数值和方位只是案例，不能复制到所有照片。

右移或换位后重新检查地理范围与投影、文字位置、线条层级及渐隐，不假定整层平移就足够；地图范围不需要改变时可以保留，避免无理由改动。记录候选的取舍、最终归一化位置及视觉复核结果。脚本评分只估计空间适用性，不具备完整的摄影审美判断。

## 核心对比度与外围透明分开控制

用整体预览检查地图能否成为可辨识的第二视觉层。若只有放大后才能读出线网，应先提高核心对比，不必继续扩大面积。浅色地图在蓝天可从更亮的暖白色开始，提高主路/水岸和主要等高线的 alpha，再微调线宽；保留次级线条层级，避免密集地形成为白块。深色背景、白云附近需结合局部明度判断，不把同一套数值当成通用预设。

仰口增强案例：暖白墨色由 #F5EDDF 调为 #FFF9ED；主要/普通等高线绘制 alpha 由175/125提高为235/185，设计线宽由0.80/0.50提高为1.05/0.68。主路和水岸进一步加实，外围沿用渐隐。这些是该照片的出发值，并非脚本新增配置键；修改渲染实现时须保存实际代码与记录，再验收整体和原生细节。旋转、裁切后重新检查线条和文字，不对原片增加全局对比度。
